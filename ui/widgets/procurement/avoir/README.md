# UI Widgets - Avoirs Fournisseurs (`ui/widgets/procurement/avoir`)

Ce sous-dossier gère les avoirs et retours de marchandises vers les fournisseurs.

## Fichiers et Rôles

- `__init__.py` : Expose le module d'avoirs.
- `CreditNoteTab.py` : Onglet principal de gestion des avoirs fournisseurs.
- `CreditNoteList.py` : Tableau récapitulatif des avoirs avec statuts et montants.
- `CreditNoteForm.py` : Formulaire de saisie et d'édition d'avoir avec sélection de lots.
- `BatchSelectionDialog.py` : Dialogue de sélection des lots à retourner.
