# دليل تصميم وتطوير واجهات المستخدم الموحدة (UI/UX Transformation Guide)
## واجهات إدارة المستودع الخاص، كاشير المعرض العام، بيع الجملة، وحوار التفكيك وطباعة الباركود

---

## 1. الخريطة الهيكلية للواجهات المحدثة (UI Structure)

```text
[ القائمة الرئيسية للتطبيق ]
├── 1. إدارة المخزون والدفعات (Inventaire & Batches)
│   ├── [شاشة دفعات المستودع الرئيسي] (tabs_batches) ➔ إدارة دفعات المستودع الخاص، النقل المباشر، والتفكيك للرفوف.
│   └── [سجل التحويلات والتفكيك الداخلي] (internal_transfers_tab) ➔ مراجعة سندات الخروج والاستلام الداخلي وتتبع الدفعات.
│
├── 2. المبيعات (Ventes & Facturation)
│   ├── [واجهة كاشير التجزئة - POS] (point_of_sale_tab) ➔ البيع السريع للمستهلك النهائي، مقصور على المواقع العامة (Public).
│   ├── [واجهة بيع الجملة والتجار - B2B] (wholesale_sales_tab) ➔ البيع بالكرتون والكميات الكبيرة، الخصم من المستودع، وفواتير A4/A5.
│   └── [سجل المبيعات والتسديدات] (sales_history_tab) ➔ تتبع عمليات البيع بنوعيها (Retail / Wholesale).
```

## 2. تفاصيل شاشة إدارة دفعات المستودع الكبير (`ui/widgets/inventory/tabs_batches`)

### 2.1. المفهوم والهدف
تُعرض هذه الشاشة افتراضياً دفعات **المواقع الخاصة (Private Locations)**، والتي تمثل البضاعة المخزنة بالجملة والكراتين في المستودع الرئيسي.

### 2.2. التحسينات البصرية والوظيفية
1. **فلترة رؤية المواقع الذكية (Location Visibility Filter)**:
   - قائمة منسدلة أعلى الجدول تتيح التبديل السريع:
     - `🏢 مخزون المستودع الخاص فقط (Private Locations) [افتراضي]`
     - `🏬 معروضات الرفوف والمعرض (Public Locations)`
     - `🌐 إجمالي المخزون الشامل (Tous les Emplacements)`
2. **شريط الأدوات والإجراءات المضافة (Toolbar Actions)**:
   - 🔄 **تحويل مباشر (Transfert Direct)**: نقل الدفعة كما هي من موقع خاص إلى موقع عام دون تفكيك.
   - ✂️ **تفكيك واستخراج للرفوف (Déconditionner & Transférer au Rayon)**: يفتح حوار التفكيك واستخراج القطع الفردية وتوليد الباركود.
   - 💼 **بيع جملة فوري (Vendre en Gros)**: تحويل بنود الدفعة المحددة مباشرة إلى واجهة مبيعات الجملة.
3. **أعمدة الجدول الدلالية**:
   - اسم المنتج ورقمه الكتالوجي.
   - الباركود الداخلي ونوع الدفعة (`Standard_Bulk` أو `Extracted_Retail`).
   - الموقع الحالي مع badge لوني يوضح الرؤية (`Private` باللون الرمادي/الأزرق، `Public` باللون الأخضر).
   - رصيد الدفعة بوحدة التخزين الحالية (`Stock_Unit`).
   - تاريخ الصلاحية مع تلوين تحذيري ذكي (FEFO).

## 3. نافذة حوار التفكيك والاستخراج وطباعة الباركود (`UnpackingTransferDialog`)

هذه النافذة هي القلب النابض لعملية تغذية المعرض من المستودع الكبير للسلع التي تباع بالقطعة:

```text
+-------------------------------------------------------------------------------+
|       📦 تفكيك واستخراج بضاعة للرفوف (Déconditionnement & Transfert Rayon)     |
+-------------------------------------------------------------------------------+
| [بيانات الدفعة المصدر في المستودع]                                            |
| المنتج: كاشف مخبري Glucose RTU       الدفعة الأصلية: LOT-2026-A                |
| الموقع المصدر: المستودع الرئيسي (Private)   الرصيد المتاح: 50 كرتونة             |
| وحدة التخزين: Carton (كرتونة)        وحدة الاستخدام: Pièce (قطعة)              |
|                                                                               |
| [معامل التحويل واحتساب الكميات]                                               |
| معامل التفكيك: 1 كرتونة = [ 24 ] قطعة (مستورد تلقائياً من بطاقة المنتج)       |
| الكمية المراد تفكيكها من المستودع: [ 2 ] كرتونة                               |
| ➔ الكمية الناتجة المستخرجة للرف: [ 48 ] قطعة                                  |
|                                                                               |
| [الموقع العام المستهدف والباركود الجديد]                                      |
| موقع الرف الهدف: [ رف المعرض رقم 3 - Magasin (Public) ▼ ]                     |
| الباركود الداخلي المولد للقطع: [ INT-EXT-948201 ] (توليد تلقائي فريد)        |
|                                                                               |
| [خيارات الطباعة والمستندات]                                                   |
| [X] طباعة ملصقات الباركود للقطع المستخرجة فوراً (عدد الملصقات: 48)            |
| [X] إصدار وطباعة سند خروج وتفكيك من المستودع (Bon de Déconditionnement)       |
| [X] إصدار وطباعة سند استلام داخلي للرف (Bon de Réception Interne)             |
|                                                                               |
|                  [ إلغاء الأمر ]      [ ✅ تأكيد التفكيك والنقل والطباعة ]     |
+-------------------------------------------------------------------------------+
```

### 3.1. الخطوات البرمجية المنجزة عند التأكيد:
1. خصم `2 كرتونة` من الدفعة المصدر في الموقع الخاص.
2. إنشاء دفعة جديدة في `Inventory_Batches` بالموقع العام برصيد `48 قطعة`، حاملة الباركود `INT-EXT-948201` ومرتبطة بـ `Parent_Batch_ID`.
3. تسجيل السند في `Internal_Transfers` بـ `Transfer_Type = 'Unpack'`.
4. إرسال أمر فوري لطابعة الباركود لطباعة `48 ملصق` للقطع.
5. فتح معاينة وطباعة سند الخروج وسند الاستلام الداخليين.

## 4. شاشة كاشير التجزئة المحدثة (`ui/widgets/sales/point_of_sale_tab.py`)

### 4.1. المفهوم والهدف
البيع السريع للمستهلك الفردي مع ضمان قصر البحث والخصم على **المواقع العامة (Public Locations / Allow_POS_Sales = TRUE)** حصراً.

### 4.2. الميزات التفاعلية
1. **فلترة البحث التلقائية**:
   - `batches_cache` في شاشة POS تستعلم حصراً عن الدفعات المتواجدة في المواقع العامة برصيد أكبر من الصفر.
2. **بطاقة الرصيد المزدوج الذكي (Dual-Stock Intelligence Card)**:
   - عند مسح أو اختيار منتج، تظهر بطاقة معلومات سريعة أعلى السلة:
     `🟢 المعروض على الرف (Public): 12 قطعة  |  🏢 رصيد المستودع الكبير (Private): 80 كرتونة`
3. **معالجة طلب كمية أكبر من رصيد الرف**:
   - إذا طلب العميل كمية تفوق المتوفر على الرف (مثلاً طلب 20 قطعة والمتوفر على الرف 12)، تظهر رسالة تفاعلية ذكية:
     `الكمية على الرف (12) غير كافية. يتوفر في المستودع 80 كرتونة. هل ترغب في فتح حوار التفكيك والاستخراج السريع لإحضار كرتونة إضافية للرف؟`

## 5. الواجهة المخصصة: مبيعات الجملة والتجار (`ui/widgets/sales/wholesale_sales_tab.py`)

### 5.1. المفهوم والهدف
واجهة أعمال B2B متخصصة لبيع الطرود والكراتين والكميات الكبيرة للتجار والعيادات والموزعين، مع الخصم المباشر من دفعات المستودع الخاص.

### 5.2. عناصر الواجهة الرئيسية
1. **لوحة العميل والائتمان التجاري (Client & Credit Dashboard)**:
   - اختيار العميل، عرض فوري لسقف الائتمان، الرصيد المستحق، وتاريخ الاستحقاق.
2. **جدول سلة الجملة (Wholesale Order Grid)**:
   - إدخال الكمية بوحدة التخزين (الكرتونة/العلبة الكبيرة).
   - تطبيق أسعار الجملة ونسب الخصم التجاري (`Remise Commerciale %`).
3. **الفوترة والطباعة المتقدمة**:
   - طباعة فواتير رسمية وسندات تسليم A4 و A5 متوافقة مع المتطلبات الجبائية والتجارية.
   - الخصم المباشر من رصيد الدفعة في المستودع الخاص مع تسجيل حركة `Movement_Type = 'Wholesale_Sale'`.

---

## 6. سجل التحويلات والتفكيك الداخلي (`ui/widgets/inventory/internal_transfers_tab.py`)

- **جدول تاريخ التحويلات**:
  - عرض كافة السندات مع إمكانية الفلترة بنوع التحويل (`Direct` أو `Unpack`)، التاريخ، والموظف.
  - إمكانية إعادة طباعة سند التفكيك وسند الاستلام الداخلي في أي وقت.
  - عرض شجرة الدفعة (Lineage View) لتتبع القطع المعروضة على الرف ومعرفة من أي كرتونة وأي دفعة أصلية تم استخراجها.
