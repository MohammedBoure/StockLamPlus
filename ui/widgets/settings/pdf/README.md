# UI Widgets - Paramètres PDF (`ui/widgets/settings/pdf`)

Gestion des paramètres avancés, tampons d'entreprise et disposition visuelle des documents PDF.

## Fichiers et Rôles

- `__init__.py` : Expose les composants de configuration PDF.
- `pdf_config_tab.py` : Onglet des champs partenaires affichés et styles de documents.
- `pdf_config_dialog.py` : Dialogue modal de configuration des documents PDF.
- `pdf_visual_editor.py` : Éditeur visuel de positionnement des blocs d'en-tête et signatures.
- `pdf_stamp.py` : Gestion des tampons/signatures partagés et redimensionnement automatique.
