# UI Widgets - Réclamations (`ui/widgets/reclamation`)

Gestion des anomalies, non-conformités et réclamations fournisseurs.

## Fichiers et Rôles

- `__init__.py` : Expose `ReclamationTab` et `ReclamationDialog`.
- `reclamation_tab.py` : Onglet principal listant les réclamations et filtrant par période.
- `reclamation_dialog.py` : Boîte de dialogue de saisie et résolution d'anomalie.
